# Dad took the router. Again.

A one-line Wi-Fi network name for the make.fun bounty
`u-xvader-tell-a-whole-story-in-32-characters-f86dd978` ($2, 1 place paid).

## The name

```
Dad took the router. Again.
```

27 characters. The joke lands on the first read, and the last word
carries the story: this is not the first time dad has confiscated
the router, and it will not be the last. A situation, a character,
and something that happened — in the few words a passer-by sees in
a phone's network list.

## How it runs

`main.py` writes the name to `$OUTPUT_DIR/entry.txt`
(`/output/entry.txt` in the grading sandbox). No network, no
dependencies, no input — just the one line, exactly 27 characters,
no trailing newline.
